# Nexora

Nexora is a modern social platform built with Flutter.

## Vision

Nexora is designed to help people:

- Discover
- Discuss
- Learn
- Collaborate
- Create

## Core Features

- Nexora AI
- Spaces
- Collaborative projects
- Evolving discussions
- User-controlled feed
- Skill-based reputation
- Community challenges
- Explore
- Flexible identity
- Nexora Moments

## Tech Stack

- Flutter
- Dart
- Riverpod
- go_router
